# Các bước để chạy project next admin này.

## B1. Chạy Mysql ở laragon và tải source .NET và chạy [https://gitlab.com/traintickethub/traintickethub.api](https://gitlab.com/traintickethub/traintickethub.api)

## B2. Khi run thì vào link này để kiểm tra API. [(https://localhost:5001/swagger/index.html](https://localhost:5001/swagger/index.html)

## B3. Tải source này Next.JS về và terminal `npm i && npm run dev`

## B4. Để vào admin cần Login vào [http://localhost:3000/en/sign-in](http://localhost:3000/en/sign-in) có thể login GG, Github và FB.
